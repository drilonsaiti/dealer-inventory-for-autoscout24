# Security policy

## Supported versions

Security fixes are released for the latest version of the plugin.

## Reporting a vulnerability

Please do **not** open a public issue. Report the problem privately through GitHub instead: open the [Security tab](https://github.com/drilonsaiti/autoscout24-inventory-plugin/security) of this repository and choose **Report a vulnerability**.

Please include:

- the plugin, WordPress and PHP versions;
- the steps to reproduce the problem;
- what an attacker can do with it.

We aim to:

- confirm receipt within 3 working days;
- publish a fix as soon as possible, usually within 14 days for serious issues.

We will credit you in the changelog unless you prefer otherwise.

## Scope

- **In scope:** the code in this repository.
- **Out of scope:** the AutoScout24 API and services, WordPress core, and other plugins and themes. Report those to their owners.
